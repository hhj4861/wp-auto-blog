## 확정된 채용 원칙

짧은 핵심 요약과 도식으로 진입하고, 판단·준비에 필요한 상세 본문을 충분히 제공한다. 단일 공고는 모집 조건, 복수 기업은 차이 비교를 보여준다. 공식 일정과 편집부 준비 제안을 구분하고, 근거 없는 연봉·인원·합격률·조건은 만들지 않는다. 마감·지원 링크·예외를 본문에서 쉽게 찾게 한다.

사이트 헤더·홈페이지 전체 교체는 이번 채용 본문 포맷 지정에 포함하지 않는다. 기존 공개 글은 일괄 수정하지 않는다. 구현 PR의 운영 머지는 해당 PR에 대한 사용자 승인 후 진행한다.

## 생활정보 검토 포인트

- 채용의 모집 비교 대신 대상/조건 분기로 ‘내 경우’를 찾기 쉽게 한다.
- 신청 흐름 뒤에 준비 사항·예외·실제 사례를 충분히 설명한다.
- 공식 사실과 편집부 설명을 분리한다. 신청 버튼은 공식 사이트 이동임을 표시한다.
- 최신 요청에 따라 나머지 네 카테고리는 통합 시안에서 함께 비교한다.

검증 기록: 채용 구현 관련 테스트 355개 통과. 생활정보 시안 데스크톱·모바일 388px 가로 넘침 없음, 목차 이동·체크리스트·FAQ 동작 확인. 기존 공개 글은 변경하지 않음.

2026-10-10 추가 요청: 생활정보 목차를 메뉴 선택형으로 변경. 다섯 메뉴의 해당 본문만 표시하며 전체 보기 지원. 배출 준비에 예외 조건을 함께 포함하고 출처는 상시 노출. 디자인 시안만 수정하며 운영 포맷 확정은 대기.

## 나머지 네 카테고리 통합 시안 — 2026-10-10

[시안 열기](trendpulse-category-concepts.html). 상단 카테고리 선택, 모바일 폭 전환, 카테고리별 상세 메뉴 5개와 전체 보기, FAQ, 체크리스트를 포함한다. 내용은 각 약 1,800~2,100자로 도식 뒤 설명과 예시를 제공한다.

- 건강: 수면 시간·질 구분, 실천 순서, 가상 기록표, 상담 안내. CDC 공식 안내를 참고하며 진단 점수를 만들지 않았다.
- 리뷰: 사용 장면, 비교표, 사양 해석, 확인 한계. USB-IF 자료를 참고한 구매 기준형 시안으로 실제품 실측·후기·가격·순위는 만들지 않았다.
- 테크: 비밀번호와 패스키 비교, 기기와 서비스의 인증 도식, 설정 준비와 복구 질문. FIDO Alliance 자료 기반이다.
- 생산성: 권한별 역할, 공유 절차, 편집부의 업무 예시, 접근 오류 확인. Google 공식 도움말 기반이다.

검증: HTML 고유 ID, 각 시안의 5개 본문 패널·4개 체크 항목, JavaScript 비활성 시 전체 본문 노출 구조, Node 스크립트 문법 검사, git diff --check 통과. Chrome 자동 연결이 반복해서 응답하지 않아 데스크톱·모바일 실제 렌더와 클릭 검증은 미완료다. 이전 생활정보 시안의 브라우저 결과를 이번 네 시안의 검증으로 대체하지 않는다.

현재 결과: 로컬 디자인 시안 작성. WordPress 및 자동 작성 경로 미적용. 다음 작업: 브라우저에서 실제 화면·상호작용 검증 후 사용자 디자인 확정.
