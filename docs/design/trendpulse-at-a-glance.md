# 핵심 먼저 보기 — 디자인 시안

2026-10-14 사용자 요청: 블로그 주요 내용이 한눈에 들어오도록 개선.

범위: 최근 건강 글을 기반으로 한 독립 HTML 디자인 문서. WordPress 및 생성 템플릿 미변경.

## 설계와 검토

- 색: 종이 #ffffff, 본문 #243047, 보조 #59677a, 건강 강조 #08776d, 요약 배경 #eef7f5, 구분선 #dfe5ee.
- 글꼴: Apple SD Gothic Neo / Malgun Gothic. 제목 26–38px, 결론 23–32px, 본문 17px, 근거 13–14px. 왼쪽 정렬.
- 구성: 제목 → 한 줄 결론 → 핵심 3항목 → 대상·기간·행동 안내 → 공식 근거 → 상세 본문과 고정 메뉴.
- 초기의 동일 카드 3개 대신 하나의 비교 띠를 사용. 수치 장식이나 위험도 게이지 없이 ‘확진 진단 부재’를 평가와 동등하게 표시한다.
- 모바일은 비교 띠를 세로 항목으로 바꾸며 가로 스크롤 없이 읽는다. 모든 본문 기본 표시, 기존 메뉴 동작 유지.
- 원래 요약과 상세 내용은 남긴다. 사실·예외를 숨기거나 위험도를 개인 진단으로 표현하지 않는다.

## 다른 카테고리에 적용할 정보 우선순위 제안

|카테고리|첫 화면에서 답할 질문|
|---|---|
|채용|누가 지원할 수 있나 / 언제까지인가 / 어디에서 지원하나|
|생활정보|대상인가 / 무엇을 준비하나 / 어디에서 신청하나|
|건강|무엇이 확인됐나 / 무엇이 불확실한가 / 어떤 조건에서 행동하나|
|리뷰|어떤 용도에 맞나 / 무엇이 다른가 / 확인되지 않은 점은 무엇인가|
|테크|무엇이 달라졌나 / 어디서 쓸 수 있나 / 어떤 제한이 있나|
|생산성|무엇을 할 수 있나 / 무엇이 필요한가 / 어디부터 시작하나|

검증: PC 1728px·모바일 390px에서 가로 넘침 없음. 메뉴 전체 5개 → 개별 1개 → 전체 5개 전환 확인. 두 화면의 스크린샷 시각 검토 완료. 기존 5개 본문 패널과 원래 요약의 텍스트 일치, ID 중복 없음, JavaScript 문법 검사 통과. 이 파일은 포맷 확정이나 운영 배포를 의미하지 않는다.
