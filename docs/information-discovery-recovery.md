- 일반 카테고리도 매 조사 회차에 이미 탈락·조사한 후보를 제외한 뒤 120개 풀을 다시 채운다.
  이전에는 최초 풀 바깥의 실측 후보가 있어도 풀이 소진된 것으로 끝났다.

  불확실한 실측 후보를 회차당 최대 2개, 실행당 최대 3개 실제 검색한다. 기각 판정을
  승인으로 바꾸는 경로가 아니다. 카테고리 불일치·중복·포괄어 판정, 미측정 검색어,
  비정상 응답, 기존 실패 보류 기간은 복구 대상에서 제외한다.

  제한된 출처 자리를 차지하지 않게 한다. 보험·비용·행정 질문은 기존 법적 근거 경로를 유지한다.
  추가 native 조사도 환자용 상세 설명과 필요시 영어 출처를 찾도록 명시한다.
- 생산성의 업무 소프트웨어 설치·계정·라이선스 질문과 건강의 일반 질환·증상 정보가
  카테고리 범위에 포함됨을 심사에 명시한다. 개인 진단·처방은 계속 제외한다.
- `기미없애는법`의 실제 오류는 `unverified_result_quote`가 두 차례 반복된 것이었다.
  검색 심사 모델이 원문 인용을 재작성하는 대신 입력의 원문 구절 번호를 고르게 한다.
  서버가 해당 검색 결과의 정확한 구절로 복원한 뒤 기존 검증을 적용한다. 잘못된 번호나

중복 검사와 최종 발행 적격성 검사는 유지한다. 조사 회차 4회와 25분의 상한도 유지한다.

## 남은 비차단 문제

- `엑셀그래프만들기`는 독립 주제 심사에서 `invalid_schema`가 2회 발생해
  `missing_topic_suitability`로 보류됐다. 이를 승인으로 바꾸지 않고 다른 후보를 발행했다.
  현재 로그에는 검증 실패 필드가 없어 구체적인 스키마 위반 원인은 확정할 수 없다.
- 발행 후 IndexNow 요청은 HTTP 403이었다. 글 공개·이미지 업로드 성공과 별개로
  검색엔진 알림은 성공하지 않았다.

따라서 신규 발행과 동적 썸네일의 운영 경로는 검증됐지만, 모든 후보의 심사 오류나
모든 외부 서비스 오류가 없어졌다는 뜻은 아니다.
