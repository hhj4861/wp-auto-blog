# 키워드 근거 검증 개선

2026-09-19 건강 카테고리 실행은 글 생성 전에 키워드 검증에서 중단됐다. CT·MRI 등의 부위별 가격 자료를 검색어보다 좁다는 이유로 관련 검색결과에서 제외했고, 최종 출처 검수에서 부족한 항목을 찾아도 추가 조사 없이 보류했다.

## 변경

- 검색 관련성 검수는 같은 대상의 핵심 질문에 필요한 부분 답변도 인정한다. 예를 들어 CT 비용에 대한 흉부 CT 가격은 관련 자료다. PET-CT만의 가격, 다른 검사, 일반 로그인·메뉴 등은 계속 제외한다. 검색결과 하나의 관련성과 글 전체의 근거 충족 여부를 구분한다.
- 출처 범위 또는 필수 항목의 근거만 부족한 후보는 부족한 질문과 기존 URL을 전달해 새 공식 본문을 조사하고 독립 검수를 다시 받는다. 기존 기획 단계의 보완과 합쳐 카테고리 선택 실행당 최대 2회, 후보당 최대 1회다. 키워드·기획·검색량·검색 표본을 바꾸지 않는다.
- 같은 URL, 복제 본문, 허용되지 않은 URL은 보완 근거가 될 수 없다. 검색 실행 확인, 실제 HTTP 본문 수집, 본문에 있는 인용, 출처 범위와 현재성 검사를 유지한다. 보완 실패 또는 재검수 실패 시 보류를 유지하며 `decision_diagnostics.coverage_recovery`에 최초 검수·부족 항목·결과를 기록한다.
- 공식 페이지의 실제 콘텐츠 영역을 우선 추출한다. 기존 div 기반 메뉴가 8,000자 발췌 한도를 차지하지 않도록 하고, 짧은 본문을 주변 메뉴로 채워 통과시키지 않는다. 추출 후 해시와 발췌문을 생성한다.

검색 품질 수치 기준과 단일 병원 가격을 전체 비용 근거로 인정하지 않는 규칙은 변경하지 않았다. TLS 검증·요청 시간 예산·재시도 제한도 유지한다.

## 검증 범위

회귀 테스트는 전송·모델 응답을 모의하고 실제 근거 결합, 인용 검증, 보류 판정, 선택 및 큐 등록을 실행한다. 모델 응답의 실제 정확도를 입증하는 테스트는 아니다.

관련 검증 944개 통과:

```sh
venv/bin/python -m pytest tests/test_source_coverage_recovery.py tests/test_search_quality.py tests/test_editorial.py tests/test_market_topics.py tests/test_topic_suitability.py tests/test_market_opportunity.py tests/test_scheduled_post.py tests/test_official_source_probe.py -q -o addopts='' --tb=short --disable-warnings
```

전체 테스트는 WordPress 호출 대기에서 중단했다(1,087 통과, 8 실패). 확인된 실패는 기존 콘텐츠 생성 테스트의 H1·검증 기대값, `suitability_evidence`가 없는 모의 데이터, 이미지 기본 개수 기대값이다. 변경한 런타임 모듈 3개를 수정 전 커밋 `3206569`에서 메모리로 읽어 같은 실패 테스트를 재실행했으며 동일한 8개 실패를 재현했다. 전체 테스트 통과로 보고하지 않는다.

공개 명지병원 피부과 건강Story 페이지를 읽기 전용으로 조회했다. 기존 추출은 10,886자 중 본문 시작이 8,667번째에 있어 발췌에서 본문이 잘렸다. 개선된 추출은 해당 콘텐츠 1,810자를 읽었다. 이는 본문 추출 확인이며 특정 건강 주장의 적합성 판정은 아니다.

작업 브랜치에서 검증하며, 운영 반영은 PR 머지 승인 이후다. 실제 건강 키워드의 선택 성공과 새 글 발행은 운영 재실행 결과로 별도 확인해야 한다.
