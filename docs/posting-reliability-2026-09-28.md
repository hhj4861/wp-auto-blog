## 변경

- 공식 출처 발견 검색은 복합 `OR site:` 식 대신 사이트별 단순 검색을 최대 4회 수행한다.
  주제별 제조사·서비스 공식 도메인을 먼저 검색하고 반환 URL도 요청 도메인에 속하는지 확인한다.
  비교 주제는 먼저 검색한 제조사 하나가 출처 4자리를 독점하지 않도록 교차 배치한다.
  측정된 원래 검색어와 일반 검색 결과는 그대로 유지하고, 검증된 띄어쓰기 표현을 출처 검색에도 전달한다.
- 삼성 제품 페이지는 홍보용 `article` 대신 실제 `#compGoodsFeatures`와 `#compGoodsSpec`을 읽는다.
  제품 영역이 비었거나 짧아도 주변 기획전·사용자 후기로 채우지 않는다.
- 스크립트가 큰 공식 HTML도 읽도록 최대 응답을 1 MB에서 5 MB로 조정했다.
  완전히 받은 HTML만 분석하며 시간 제한, HTTPS·공식 도메인·리다이렉트 검증, 최소 본문 길이는 유지한다.
- 한 번의 선정 작업 안에서 최대 128개 출처 응답을 재사용한다. 최종 실패한 동일 URL의 반복 조회도 줄인다.
  다음 작업에는 캐시를 넘기지 않으며, 반환 객체 수정이 다른 후보의 근거를 오염시키지 않는다.
- WordPress 목록의 기존 연결 오류 재시도 예산 1회를 HTTP 502/503/504에도 공유한다.
  401/403·TLS 오류·잘못된 데이터는 계속 즉시 중단한다. 타임아웃·연결·TLS 실패 로그를 구분한다.
  일부 페이지만 읽은 목록으로 중복 검사를 통과시키지 않는다.
- 정상적으로 조사했지만 후보가 없는 경우 `no_candidate_passed`와 탈락·보류 건수를 출력한다.
  예외 발생의 `selection_failed`와 구분하며, 두 경우 모두 발행은 보류한다.

## 검증

- 관련 13개 테스트 파일: **1,408개 통과**. 출처 수집·검색·선정·품질/근거·초안·중복·예약·목록 진단을 포함한다.
- 삼성 [Bespoke AI 제트 Lite 제품 페이지](https://www.samsung.com/sec/vacuum-cleaners/bespoke-jet-vs28d950ac-d2c/VS28D950ACB/)
  실조회에서 기존 추출은 추천 기획전 약 455자였다. 수정 후 실제 제품 영역 약 2만 5천 자에서
  흡입력·시험 조건을 포함한 8,000자 근거를 확보했다. 이 결과는 해당 페이지의 추출 확인이며 글 발행 승인은 아니다.
- 큰 스크립트 뒤에 본문이 있는 1.5 MB HTML, 5 MB 초과 거절, 짧은 제품 본문 거절,
  캐시의 중첩·변경 격리·실패 후 해제·다음 작업 재조회, 제조사별 출처 배치, HTTP/연결 오류 공유 재시도를 검증했다.
- 공개 DuckDuckGo 조회에서 `종합소득세 환급일 site:korea.kr`, `무선 청소기 비교 site:samsung.com`이
  관련 공식 자료를 반환했다. 같은 시점 기존 복합 식도 관련 결과를 반환했으므로 과거 무관한 결과의
  유일한 원인을 복합 식으로 확정하지 않는다. 검색 결과는 시점과 제공자에 따라 변한다.
- 운영 [읽기 전용 WordPress 진단](https://github.com/hhj4861/wp-auto-blog/actions/runs/36368448569):
  9/28 11:05 KST, view/edit 각각 4페이지 397개 항목 모두 HTTP 200, 제목·메타 구조 정상.
  과거 403·transport 오류의 서버 내부 원인은 확정하지 못했으며 이 변경이 403을 해결했다고 주장하지 않는다.
