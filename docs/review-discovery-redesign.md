# 리뷰 후보 발굴 개편 — 2026-10-01

상태: PR #73은 사용자 승인 후 운영에 반영됐다. 머지 후 실제 리뷰 실행은 실패했으며 신규 리뷰 포스트는 발행되지 않았다.

## 확인한 구조적 원인

운영 실행 36851181381은 341개 실측 후보 중 303개를 사전 단어 검사로 제외하고 한 개만 조사했다. 고정된 6개 제품군에 없던 SSD·RAM은 제품 미식별로, 숫자로 표현된 용량·화면 크기는 구매 질문 범위 부족으로 처리됐다. 예를 들어 SSD1TB, 외장SSD2TB, 17인치노트북은 실제 API가 반환한 후보였지만 검색·본문 조사에 도달하지 못했다. 반면 공기청정기 필터의 표기 변형은 목록에 남았다. 고정 보충 시드 12개가 끝나면 새 질문을 발견할 경로도 없었다.

유튜브 키 오류는 별도 문제다. 이 수정은 유튜브가 없어도 기존 네이버 실측을 사용하며, 검색량을 추정하거나 심사를 통과한 것으로 간주하지 않는다.

## 변경

- 저장장치와 RAM을 독립 제품으로 인식한다. 제품만 있는 SSD, RAM, 삼성SSD 등 포괄어는 계속 제외한다.
- 용량·화면 크기·DDR/NVMe/SATA 규격을 구체적인 조건으로 인식한다. DDR416GB에서 DDR 세대 숫자가 416GB 용량으로 합쳐지지 않게 구분한다.
- 실제로 내려받은 공식 본문에서 요청한 용량·화면 크기·규격이 확인돼야 출처 후보로 쓴다. 1TB 대신 2TB/11TB/TBW, DDR4 대신 DDR5, 17인치 대신 16인치를 붙이지 않는다. 비교 질문은 개별 문서가 한 비교 대상을 지원할 수 있지만 최종 독립 심사는 전체 질문을 확인한다.
- 기존 고정 시드가 소진되면 실측 목록의 제품 명칭에 근거해 새 질문을 최대 4개 제안한다. 질문에는 anchor 문구가 실제 포함돼야 하며 제외 이력·중복·카테고리 범위와 형식을 검증한다. 이것은 미측정 조회 힌트일 뿐이며 제안된 수요·인기·URL을 받지 않는다.
- 새 시드의 연관어는 네이버에서 각각 다시 측정한다. 기존 월 500회 하한, 키워드별 보류 기간, 중복, 검색 관련성, 공식 본문, 독립 심사와 최종 본문 검사를 유지한다. 최대 4회 탐색 회차와 25분 예산도 유지한다.
- 선정 보고서에 질문 제안과 실제 수요 조회 결과를 분리해 남긴다. 기술 오류는 공통 고정 오류 처리 경로를 사용한다.

## 사전 실측 점검

기존 Blog Keyword Select에 demand_check_only를 추가했다. 별도 job에서 네이버 자격 3개만 사용하고 contents:read로 실행한다. 이 모드에서는 Codex 인증/모델, 다른 진단 job, WordPress, 보고서 저장과 발행 job을 실행하지 않는다. 작업 브랜치에서 읽기 전용 네이버 조회를 검증할 수 있으며 Codex의 main 전용 인증 정책은 그대로다.

점검 결과는 발견 단계 후보 수일 뿐이다. 저장된 발행 이력과 키워드별 보류를 적용하지만 최신 WordPress 전체 목록·검색 의도·출처 심사를 실행하지 않으므로 publish eligible로 보고하지 않는다.
