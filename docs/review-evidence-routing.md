# 리뷰 출처 연결과 새 질문 탐색 — 2026-10-02

## 운영에서 확인된 결과

PR #74는 사용자 승인 후 main 8fdf772로 머지했다. 실행 36935231882는 2026-10-02 07:28 KST에 시작해 07:41 KST에 선정 실패로 종료했다. 검색어 변환 오류는 0건이었고 후보 11개 모두 검색으로 진입했다. 다만 8개는 검색 관련성·사이트 편중 기준 미달, 2개는 공식 출처 부족, 1개는 검색 기술 실패로 제외됐다. 선정 0개로 작성·발행에는 도달하지 못했으며 새 리뷰 포스트는 없다.

실측 263개, 조사 풀 27개, 4회차에서 종료했지만 새 질문 제안 상태는 not_needed였다. 기존 후보가 남아 있으면 새 질문을 발굴하지 않는 조건 때문에, 비슷한 구매어를 조사하다 회차가 끝났다. 외장하드1TB·HDD1TB에는 Sandisk SSD 제품 자료가 연결됐다. SSD/HDD가 같은 저장장치 제품군에 속한다는 사실을 실제 출처 호환으로 잘못 취급한 것이다. SSD 광고에서 비교 대상인 HDD를 언급해 단어 검사까지 통과한 사례도 있었다.

## 보완

- HDD 질문의 공식 검색 경로를 Seagate·Toshiba로 분리하고 씨게이트·도시바 브랜드 조건을 적용한다. SSD 경로는 유지한다.
- 실제 출처의 제품 종류·외장 여부·용량을 확인한다. SSD 제품 제목과 HDD 요청처럼 제품이 다르면 광고 본문에 HDD가 언급돼도 제외한다. 최종 의미 심사는 계속 필요하다.
- 한 회차를 조사했으나 통과 후보가 없으면 기존 후보가 남아 있어도 새 질문 제안을 최대 한 번, 4개까지 실행한다. 같은 제품·판단 항목의 브랜드나 용량만 바꾼 재제안은 제외하고 새 판단 항목을 찾는다.
- 제안은 조회 힌트이며 실제 네이버 측정·월 500회·중복·보류 이력을 거친다. 새로 측정된 후보는 다음 회차에 우선 제시하지만 검색·본문·독립 심사·편집 조건은 동일하다. 전체 4회차·25분 예산도 유지한다.
- 네이티브 검색의 고정 프로토콜 오류 코드를 진단에 그대로 보존한다. unclassified 한 건의 과거 원인을 추정해 특정 코드로 소급하지 않는다. 안전 경계 오류를 재시도하거나 완화하지 않는다.

## 검증과 한계

관련 19개 모듈 1,106개 통과(9.36초). 실제 실패 자료의 URL·제목과 추출된 단어만 fixture로 최소 보존했고, 잘못 연결된 SSD 자료 5개를 모두 제외함을 검증했다. fixture는 완전한 공식 본문이나 발행 근거가 아니다. 기존 후보가 남은 상태에서 새 질문을 측정해 다음 회차에 조사하며, 출처 부정 판정이면 여전히 큐에 넣지 않는 것을 확인했다.

실제 fetch_source로 [Seagate Portable](https://www.seagate.com/products/external-hard-drives/portable-drive/) 본문 8,000자와 [Toshiba Canvio Basics](https://www.toshiba-storage.com/products/canvio-basics/?form=MG0AV3) 본문 5,154자를 읽었다. 두 문서 모두 외장 HDD·1TB의 사전 조건을 충족했다. 전체 구매 질문에 대한 독립 심사나 새 글 발행을 통과했다는 뜻은 아니다.

이 보완은 구현 브랜치에서 커밋·push하며 운영 미반영이다. 새 질문의 실제 모델 제안부터 공개 발행까지는 해당 PR의 명시적 머지 승인 후 main에서 검증해야 한다. YouTube API 키 오류도 별도 미해결이다.
