# 리뷰 구매 의도와 선정 증거 보완

## 실제 실패에서 확인한 범위

PR #68 운영 실행 `36816004840`은 후보를 3개 조사했지만 발행 후보를 확보하지 못했다. 노트북램은 `category_mismatch`, 가벼운무선청소기는 `insufficient_search_intent`, LG공기청정기필터는 검색 품질 부족으로 탈락했다. 앞의 두 후보는 당시 검색 표본이 탈락 행에 남아 있지 않아 모델 판정의 적절성을 재현할 수 없었다. 이번 보완은 이 제약과 리뷰 목적 안내의 불일치에 집중한다.

## 변경

- 후보 제안·공식 자료 기반 기획·독립 범위 심사에서 동일한 리뷰 목적 안내를 사용한다. 구매 전 사양·조건 비교와 판매처 이동·주문만 원하는 목적을 구분한다. 상품 페이지의 존재만으로 정보 목적을 부정하거나, 선택 기준 글에 모든 판매 모델의 순위·최저가·직접 체험을 자동 요구하지 않는다. 실제 검색 근거, 비교 조건 및 기획이 약속한 범위는 여전히 검증한다.
- 빈 제안 뒤 추가 조사에서도 알려진 한국어 제품군·판단 항목에 ASCII 공백을 넣는다. 예: `가벼운무선청소기` → `가벼운 무선청소기`, `노트북램` → `노트북 램`. 기존 엄격한 검색어 검증기로 문자·숫자·대소문자·연산자 변경을 차단하며, 띄어쓰기 보정이 허용되지 않으면 원문을 유지한다. 실측 keyword와 수요는 바꾸지 않는다.
- 출처 기반 기획에서 탈락한 리뷰 후보에도 실제 검색 결과, 실행 검색어, 검색 관련성 검수, 공식 본문·해시를 저장한다. 출처의 임의 추가 필드는 보존하지 않는다. 다음 후보 제안 프롬프트에는 탈락 요약만 넣어 본문이 누적되지 않게 한다.

검색량 하한, 검색 품질 임계값, 중복, 쿨다운, 제품군/판단 항목 필터, 실제 출처 인용과 최종 발행 자격 검사는 유지한다. 과거 실패를 지우거나 자동 승인하지 않는다. 범위 전체가 맞는지와 실제 사용 경험 없는 리뷰의 한계는 계속 심사한다.

## 검증 구분

로컬 회귀는 외부 응답을 모의하므로 운영 발행 성공을 입증하지 않는다. 작업 브랜치의 `Blog Keyword Select` 실행으로 실제 선정 검증을 시도했으나, 실행 `36818410157`은 인증 복원 단계에서 차단됐다. `require_private_actions()`가 Codex 인증을 기본 브랜치의 승인된 자동화에만 허용하기 때문이다. 이는 후보 심사 실패가 아니며 새 선정 결과를 만들지 않았다. 해당 실행의 artifact는 checkout에 있던 기존 보고서로, 새 검증 증거로 취급하지 않는다. 로컬 `.trendpulse-codex`에는 전용 auth 파일이 없어 로컬 운영 모델 검증도 수행하지 못했다. 인증 정책·Secret·브랜치 판별을 변경하지 않았다. 머지 전 실제 모델 검증이 가능하다고 판단했던 사전 점검은 잘못됐으며, 실제 선정 검증은 승인된 머지 후 main에서 수행해야 한다.

실제 발행은 해당 PR의 머지 승인과 통합 후 검증이 필요하다. 실제 선정과 공개 발행은 별개의 결과로 보고한다.
