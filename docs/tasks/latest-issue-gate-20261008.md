## 검증 및 구현

- 비공개 처리: 실행 37732778493 success, API `post_id=1862, status=draft, verified=True`, 공개 주소 HTTP 404. 제목·본문·미디어·원 게시일 보존. 이력 삭제/재발행 없음.
- 모든 카테고리에 KST 전일 00:00~현재의 새 발표/변경/사건 근거를 필수화. 공식 원문 발행일/본문 날짜와 사건 인용, 주된 질문의 일치를 검사. 수정일·조회일·검색량으로 대체 불가.
- 최신 원문 발견 검색 2개, 최대 8개 HTTP 원문을 통해 시드 추가. 원문에서 읽은 publication_dates 보존. 기존 테크 설치·초기화·백업 시드 제거. 보고서에 쿼리·결과·원문·관찰 날짜·탈락 사유 저장.

- 버전 7 및 latest_issue_evidence 없는 기존 후보 거부. 큐/캐시/작성/최종 본문/초안 복구 재검증. 작성 직전 원문에서 동일 사건과 날짜를 확인하며 최종 본문이 새 소식을 중심으로 다루지 않으면 보류.
- 실제 윈도우11 후보 고정 자료로 기존 검색·출처·점수 관문은 통과하지만 최신성 누락으로 거부되는 것을 재현. 최신 이슈 통합 검사는 네트워크·모델만 대역으로 두고 선정→캐시→큐 실제 검증을 실행했다. 날짜 경계·미래 시각·원문 변경·신선한 검색 요약으로 오래된 원문 포장·형식 오류를 검사.
