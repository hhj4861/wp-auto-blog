완료 기준: 실제 WordPress 출력과 desktop/mobile 스크롤·클릭·키보드·체크 검증, 본문/제목/게시일 보존, 자기 변경 커밋·upstream push, 새 PR의 별도 승인 전 main 미반영.

## 검증 및 운영 결과

- 기준 PR #109는 사용자 승인에 따라 0680a90으로 머지했다. 이번 고정 메뉴는 별도 수정이다.
- 본문 너비: 실제 테마의 620px 제한을 해제하고 1040px 읽기 틀을 복원. 데스크톱 메뉴 176px + 본문 754px, 요약 강조와 표/단계의 카테고리 색을 시안에 맞춤.
- 모바일 390px: 테마의 content-box 여백 넘침을 수정, 본문 오른쪽 360px. wrapper-outer의 overflow:hidden 때문에 sticky가 동작하지 않던 것을 해당 포맷 글에서만 overflow:clip으로 조정.
- 메뉴 고정: 데스크톱 본문을 내린 상태에서 메뉴 top=16px. 모바일 상단 광고 bottom=124px일 때 메뉴 top=132px, 본문은 스크롤되지만 메뉴 유지. 선택 변경 시 panelTop=273.36px, menuBottom=257.5px로 본문이 메뉴 아래에 보임.
- WordPress/LiteSpeed 공개 출력에서 비교식 사이의 &&가 &#038;로 바뀌어 SyntaxError가 발생한 것을 직접 재현. 인라인 JS의 < 기호가 HTML로 해석되지 않도록 비교식을 반대로 작성. 공개 페이지 재조회에서 tablist 초기화 및 클릭을 다시 확인.
- 기존 고유 패널 ID 및 깊은 링크 보존, WordPress의 메뉴 내부 p 래퍼 정리, 위/아래 키 지원, 선택 변경 시 본문 시작 이동. JS 미실행 시 전체 본문과 앵커 링크 유지.
