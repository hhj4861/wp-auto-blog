## 채용 기본 구성: recruitment-reader-v1

핵심 답변 → 확인된 마감 안내 → 접이식 목차 → 모집 조건/회사 비교 → 공식 전형 일정(있는 경우) → 상세 직무/조건 해설 → 편집부 준비 단계와 구체적 예시 → 최종 점검 → FAQ → 공식 출처.

본문은 흰 배경·짙은 글자, 청색 강조, 라벤더 마감 안내, 비교 구획과 모바일 세로 일정으로 표현한다. 시안의 사이트 헤더/홈/미리보기 버튼은 본문 템플릿에 포함하지 않는다. WordPress 테마 전체 변경은 별도 범위다. 사실을 압축하다 누락하지 않도록 상세 해설과 준비 설명을 필수로 둔다. 존재하지 않는 일정·연봉·인원은 채우지 않는다. 자격증/면접 등 상시 취업 글도 같은 읽기 구성을 사용하되 존재하는 조건·절차만 쓴다.

- `src/recruitment_format.py`: 작성 규칙·구조 점검·본문 서식의 기준.
- `src/content_generator.py`: 모든 제공자의 general/취업 작성에 규칙 추가. 구조 재시도 및 근거 수정 후 재검사. 미충족 결과는 기존 발행 게이트에서 보류.
- `src/article_format.py`: category=취업에만 신규 스타일 적용. 다른 카테고리는 기존 서식 보존.
- 기존 저장된 초안 일괄 재작성/기존 공개 글 소급 변경은 하지 않는다. 새로 생성된 초안의 후속 발행은 저장된 포맷을 보존한다.

## 카테고리 확정 순서

채용: 사용자 확정 → 생활정보: 다음 시안 검토 → 건강 → 리뷰 → 테크 → 생산성.
다른 카테고리는 하나씩 시안을 보고 확정한 뒤 작성 경로에 적용한다. 생활정보 독립 시안은 현재 프로젝트 docs/design에 저장하며 실제 자동 작성에는 아직 적용하지 않는다.

## 검증 기록

- 관련 검증 355개 통과: test_recruitment_format, test_article_format, test_content_generator, test_editorial, test_post_format, test_canon_template, test_codex_draft. API/작성 모델 호출은 mock으로 격리.
- 실제 브라우저에서 채용 렌더러 데스크톱과 390px 본문, 목차 링크, 준비 번호 목록, 접이식 FAQ 확인.
- 초기 광고 프레임의 880px 고정폭이 축소 화면으로 넘치는 현상을 재현하고 슬롯 overflow containment 보완. 최종 390px 본문의 clientWidth/scrollWidth 모두 390, 광고 슬롯 310px.
- FAQ 스키마가 접이식 질문 구조에서도 재생성됨을 확인. 근거 수정이 승인된 클래스나 필수 상세 설명을 제거하면 보류하는 회귀 테스트 포함.
- 생활정보 독립 시안은 데스크톱/388px 모바일에서 가로 넘침 없음, 목차·체크리스트 카운트·FAQ 확인. 공식 이용안내/FAQ 기준 2026-10-10 자료 확인.
- 운영 WordPress 쓰기·실제 LLM 생성은 수행하지 않음. 로컬 렌더와 모의 작성 경로 검증이며, 운영 테마/WordPress 저장 후 최초 실제 글 검증은 머지 뒤 필요.
- 검증 서버는 종료. 테스트 임시 산출물: 지정 iCloud gpt 작업/wp-auto-blog/recruitment-reader-format-20261010.
