## 변경과 검증 범위

- 카테고리를 출처 수집 단계까지 전달. 테크·생산성은 제조사/서비스 문서를 검색하고 일반 기관 도메인으로 폴백하지 않는다.
- TP-Link/ipTIME 공식 도메인 추가. 출처의 요청/최종 도메인과 명백한 주제 불일치를 확인해 슬롯 낭비를 방지한다. 본문·검색 의도·범위에 대한 기존 독립 심사는 유지한다.
- 테크의 불확실한 대체 후보는 설치·설정·초기화 등의 구체적인 질문을 우선한다. 갤럭시S25 같은 제품명만의 후보가 대체 조사 예산을 선점하지 않는다. 정규 심사에서 근거를 갖춘 후보까지 금지하는 것은 아니다.
- 모든 카테고리의 탈락 입력을 보존. `source_discovery_audit`에 요청 검색문, 반환된 공개 검색 결과, 조회 URL/최종 URL, 본문 길이, 고정 HTTP 오류 코드, 도메인/주제 배제 이유를 저장한다. 네이티브 자유 조사에서는 확인된 주소 후보를 기록하며 검색 도구 내부의 전체 질의를 입증한다고 표현하지 않는다.
- `selection_funnel`과 `selection_outcome=research_budget_exhausted`로 조사 제한 종료를 전체 후보 부적합과 구분한다. 재시도·시간 제한·발행 기준을 낮추지 않는다.
- 실시간 HTTP: TP-Link [초기 설치](https://www.tp-link.com/kr/support/faq/3316/) 2,027자, [웹 설정](https://www.tp-link.com/kr/support/faq/3841/) 4,514자 확보. 출처 접근 성공이며 발행 통과 결과는 아니다.
- 로컬 전용 구독 계정의 네이티브 검색 실호출은 `unauthorized`. 오늘 운영 실행은 검색 응답을 받았으므로 두 환경의 인증 상태를 혼동하지 않는다. 검색부터 선정/발행까지의 라이브 검증은 아직 미완료.
