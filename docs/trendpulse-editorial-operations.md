## 기존 글 갱신

`Apply Reviewed Editorial Updates`는 기본 미리보기다. 적용 전 raw JSON과 적용 예정 payload를 GitHub artifact에 저장하고, 준비 중 수정 여부를 확인한다. 기존 URL·발행일·공개 상태를 보존한다. 7일을 넘긴 수정 manifest는 재검토 전 적용하지 않는다.

`Refresh Search Winners`는 화/금 06:00 KST에 실행된다(플랫폼 큐로 지연될 수 있음). 최근 28일 중 데이터 지연을 고려해 마지막 3일을 제외한다. 클릭 3회 이상, 평균 순위 20 이내, 마지막 수정 7일 이상 지난 취업 글을 클릭순 최대 2개 갱신한다. 검토를 통과해야만 반영하며 백업 artifact는 90일 보관한다. 실패 시 Actions 결과와 `results.json`에 사유가 남는다. 모델 호출량은 기존보다 증가한다.

수동 실행은 기본 후보 조회만 한다. 실제 갱신은 `apply=true`다. 백업을 복구할 때는 해당 ID의 content.raw/title.raw/excerpt.raw/featured_media/meta를 확인해 필요한 필드만 업데이트한다. 원래 slug/status/date는 유지한다.

## 검색 유입 운영

1. 현재 상위 유입 주제(GSAT·공채·외항사·NCS)의 사실 정확도와 공식 지원 경로를 우선 관리한다. 조회가 없는 주제를 무작정 늘리지 않는다.
2. Search Console에서 노출은 있으나 클릭률이 낮은 검색어를 주별 비교한다. 실제 공고가 있는 범위에서 기업·모집시기·직무 등 구체적 질문을 답한다. 기존 글과 같은 검색 의도면 새 URL 대신 기존 글을 보완한다.
3. Google은 독창적 분석, 충분한 답변, 신뢰할 수 있는 근거를 권장한다. 날짜만 바꾸거나 발행량을 늘리는 방식은 피한다: https://developers.google.com/search/docs/fundamentals/creating-helpful-content
4. 변경 후 28일의 검색 클릭·노출·CTR과 AdSense 페이지뷰·광고 노출·페이지 RPM을 이전 동기간과 비교한다. 수익 또는 순위 상승을 보장하지 않는다. 이번 감사에는 AdSense 계정의 실제 수익 보고서가 포함되지 않았다.

## ChatGPT Pro와 작성 모델

현재 코드는 Claude 작성(Agent SDK OAuth 우선), Gemini 검색, OpenAI gpt-4o-mini 대체 경로를 사용한다. 이번 변경은 작성 모델을 유지한다.

Pro는 글쓰기 특화 모델명이 아니라 구독 플랜이다. Codex의 ChatGPT 로그인은 구독 한도를 사용하며, API 키 방식은 별도 사용량 과금이다. 따라서 Pro 결제만으로 GitHub Actions의 OpenAI API 호출이 구독 요금에 포함되지는 않는다.
