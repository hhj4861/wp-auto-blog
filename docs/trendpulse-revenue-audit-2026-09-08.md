# TrendPulse 수익 개선 점검 — 2026-09-08

TrendPulse는 광고가 실제 송출되고 검색 유입도 발생한다. 현재 확인된 가장 큰 제약은 구글 검색 유입 규모이며, 이미 반응이 있는 취업·채용 글의 최신성·출처·독자 경험을 개선하는 것이 우선이다. 검색 성과가 낮다는 이유만으로 글을 일괄 삭제하거나 사이트 전체 주제를 즉시 바꿀 근거는 없다.

## 범위와 한계

- 기존 읽기 전용 GSC Performance Report를 TrendPulse 속성으로 실행했다. [실행 기록](https://github.com/hhj4861/wp-auto-blog/actions/runs/34189275966).
- 홈페이지, 여권 재발급, 대기업 공채, GSAT 글을 실제 브라우저에서 확인하고 발행 코드를 대조했다. 여권 글은 모바일 너비 390px로 새로 로드해 점검했다. 임시 화면 크기는 복구했다.
- ads.txt와 robots.txt를 공개 HTTP로 확인했다.
- 애드센스 관리 화면의 수익·페이지 RPM·광고 게재율, GA4 전체 유입, 실제 이용자의 Core Web Vitals는 미확인이다. 따라서 수익액과 광고 배치 변경의 증감 효과는 확정하지 않는다.
- 사이트, 발행글, 광고 설정, 운영 코드는 변경하지 않았다.

## 1. 검색 성과: 취업 글에 개선 자원 집중

조회 요청은 28일이며 스크립트가 사용한 날짜는 2026-08-11~2026-09-08이다. 양 끝 날짜 포함 방식과 최근 잠정 데이터를 감안해야 한다. 날짜별 반환 데이터는 9월 7일까지 보인다.

| 페이지별 집계 지표 | 결과 |
|---|---:|
| 검색 클릭 | 199 |
| 검색 노출 | 4,470 |
| 계산 CTR | 4.45% |
| 노출이 발생한 페이지 | 183 |
| 노출 가중 평균 순위 | 7.5 |

183은 전체 색인 수가 아니다. 검색 클릭은 방문자·세션·페이지 조회수와 다른 지표다. 페이지별 합산 노출 4,470과 날짜별 합산 4,461에는 집계 차이가 있어 섞어 계산하지 않는다.

| 글 | 노출 | 클릭 | CTR | 평균 순위 |
|---|---:|---:|---:|---:|

| 에미레이트 관련 글 | 436 | 26 | 5.96% | 6.7 |

상위 5개 글이 클릭 123회, 전체 페이지별 합산 클릭의 61.8%를 차지한다. 조회 기간의 검색 클릭은 하루 약 7회 수준이다. 다른 유입 채널이 많지 않다면 애드센스 수익 규모도 작을 가능성이 크다. 이는 실제 애드센스 수익을 측정한 결과는 아니다.

제안: 앞으로 4주간 개선 시간을 취업·채용 상위 글에 먼저 배정한다. JAL·에미레이트는 확인된 유입을 유지하고, 공채·GSAT·NCS는 독자가 찾는 일정·자격·공식 접수를 앞부분에 배치한다. CTR 수치는 검색어·기기·순위 구성의 영향을 받으므로 글끼리 단순 비교해 제목만 원인으로 단정하지 않는다.

## 2. 최우선: 유입 글을 공식 발표에 맞춰 갱신

[공채 글](https://trendpulse.blog/daegieop-gongchae-2026-hbangi/)은 삼성 접수를 9월 초 약 9/1~9/8 예상으로 안내한다. [GSAT 글](https://trendpulse.blog/gsat-exam-schedule-2026-second-half/)도 하반기 공고가 미발표라고 안내한다.

그러나 [삼성의 9월 7일 공식 발표](https://news.samsung.com/kr/%EC%82%BC%EC%84%B1-2026%EB%85%84-%ED%95%98%EB%B0%98%EA%B8%B0-%EA%B3%B5%EC%B1%84-%EC%8B%A4%EC%8B%9C)는 접수 9/8~9/15, GSAT 10월, 19개 관계사를 안내한다. 10월의 정확한 시험일은 이 보도자료만으로 확정하지 않는다.

조치:

1. 두 글의 요약·표·FAQ·결론을 일관되게 갱신한다. 접수 일정과 GSAT 세부 시험일의 확정 수준을 구분한다.
2. 표에 기업, 접수 시작/마감 시각, 진행 상태, 공식 공고 링크, 마지막 확인일을 둔다. 다른 기업 일정은 각각 다시 검증한다.
3. 비교표와 공식 지원 링크를 서론보다 앞에 둔다. 반복되는 중요성 설명은 줄인다.
4. 기존 URL을 유지하며 변경 내역을 남긴다. 신규 글로 같은 검색 수요를 반복 생산하지 않는다.
5. 일정형 글에는 공식 공고 변경 감지와 검수 후 갱신 절차를 마련한다. 출처 없이 날짜만 최신화하지 않는다.

## 3. 최우선: 공식 출처 링크가 제거되는 생성 후처리 수정

`src/content_generator.py:2859`의 `_sanitize_external_links()`는 제한된 도메인 목록 밖의 외부 링크를 괄호 텍스트로 변환한다. 목록에 정부24, 외교부, 삼성 채용 도메인이 없다. 호출 위치는 같은 파일 1580행이다.

실제 여권 글의 참고 자료에는 정부24·외교부 이름이 있으나 링크가 없다. 공채·GSAT 글의 삼성커리어스 등도 일반 텍스트다. 이후 삽입되는 CTA만 남으며, 공채 CTA는 개별 기업 공고 대신 고용24 홈으로 연결된다.

조치: 수집 단계에서 검증한 출처 URL을 별도 자료로 보존하고 최종 HTML까지 유지한다. 호스트명은 URL 파싱 후 정확히 검증한다. 승인된 도메인이라고 해당 문장까지 검증됐다고 취급하지 않는다. 신청 버튼은 실제 공고/서비스 상세로 연결하고, 검증되지 않은 URL은 발행 전에 보완한다. 오래된 글은 없어졌던 상세 URL을 임의 복원하지 말고 원문을 다시 찾는다.

## 4. 최우선: 기준일 자동 생성과 본문 날짜 불일치 해소

`src/monetization.py:642`의 `add_policy_disclaimers()`는 실제 사용한 자료 날짜를 받지 않고 현재 월로 '공식 발표 자료를 기준으로 작성'했다는 문구를 만든다.

홈페이지의 청년일자리도약장려금 글 요약에는 '2026년 09월 공식 발표 자료'와 '마지막 업데이트: 2026년 1월'이 함께 표시된다. 이는 독자가 정보의 적용 시점을 판단하기 어렵게 한다.

조치: 발행일, 검수일, 제도 시행일, 원문 발표일을 구분한다. 실제 검증 기록이 없으면 최신 공식 자료를 확인했다고 표시하지 않는다. 누락·불일치는 발행 전 검수 대상으로 보낸다. [Google도 실질적인 변경 없는 날짜 갱신을 경계한다](https://developers.google.com/search/docs/fundamentals/creating-helpful-content).

## 5. 중요: 대표 이미지와 섹션 이미지를 정보 중심으로 교체

여권 글에는 거실 사진, GSAT 글에는 위성 접시·태양광 패널·실험실 장비 사진이 들어 있다. `src/image_fetcher.py`는 키워드 매핑 실패 시 `lifestyle modern`으로 검색하며, 영문 단어를 먼저 추출하는 방식도 GSAT의 다른 의미와 혼동할 가능성이 있다. 개별 이미지가 어떤 경로로 선택됐는지는 실행 로그로 추가 확인해야 한다.

조치: 공채 일정표, 응시 환경 체크리스트, 실제 공식 신청 화면처럼 해당 질문에 도움이 되는 시각 자료를 우선한다. 적합한 이미지가 없으면 생략한다. 대표 사진과 모든 H2 사진을 채우는 것을 품질 조건으로 삼지 않는다. 제작한 자료를 실제 시험 화면이나 공식 문서로 오인시키지 않는다.

## 6. 중요: 모바일의 답변 도달 거리와 광고 배치 개선

여권 글 모바일 새 로드에서 광고가 실제 송출되는 것을 확인했다. 해당 방문의 DOM 측정상 제목은 상단 약 419px, 첫 H2는 약 2,214px, 신청 절차 H2는 약 4,199px, 수수료 H2는 약 5,874px에 위치했다. 광고는 방문마다 달라지므로 고정적인 사이트 성능 지표가 아니다.

핵심 정보가 대표 이미지·고지·일반적인 서론·광고 뒤에 있다. '수수료'를 찾는 독자는 많이 내려가야 한다.

조치: 제목 다음에 신청 대상·비용·준비물·공식 링크 요약과 목차를 배치한다. 장식용 대표 이미지는 축소/생략한다. 자동 광고와 본문 수동 광고를 함께 보고 제목/핵심 요약 주변 배치를 조정한다. 광고 수를 늘리는 작업은 후순위다. 광고 축소가 수익 증가를 보장하지 않으므로 페이지 RPM뿐 아니라 총수익·참여·다음 글 이동을 함께 본다. [AdSense는 광고 개수·간격·제외 영역을 제공한다](https://support.google.com/adsense/answer/9305577?hl=en).

390px로 크기만 바꿨을 때의 데스크톱 광고 잔상은 모바일 결함 근거에서 제외했다. 위 관측은 모바일 크기로 새로 로드한 결과다. 실제 모바일 사용자 LCP/CLS/INP는 미측정이다.

## 7. 중요: 다음 글과 제휴 추천의 문맥 일치

공채 글과 GSAT 글에 동일한 '승무원 준비 추천템'이 붙는다. 여권 글의 관련 글에는 퇴직연금과 통신비 환급이 포함된다. 관련 글 코드는 최근 30개를 중심으로 키워드 및 카테고리 점수를 매기고 최소 관련도 기준 없이 상위 3개를 선택한다 (`src/pipeline.py:170`, `:654`).

조치: 공채 → GSAT → 면접, 외항사 일정 → 지원 자격 → 영어 인터뷰처럼 독자의 다음 과제를 연결한다. 오래된 관련 글도 후보에 포함하고 연결할 글이 없으면 억지로 3개를 채우지 않는다. 승무원 제휴 박스는 항공 취업 문맥에서만 검토하고, 제휴 링크가 남는 경우 고지도 유지한다.
